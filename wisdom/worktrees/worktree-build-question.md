Build without installing. scripts/build-web.ts always runs pnpm install --frozen-lockfile before typecheck and bundle, even when the canonical source already has node_modules. Instead, use the existing dependencies to run the same verify, typecheck, web build, server bundle, deploy, and archive commands. Then run build.ts --reuse-web --outfile=dist/die-worktree-production. This leaves both the installed executable and dependency set alone. If “no install” meant only “do not install the executable,” main can choose the normal build command. Implementation does not need to wait for that choice.
