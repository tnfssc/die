# v0.8.0 stable candidate handoff

Prerelease d778ad2/b6f6142 shipped an isolated Mac helper bundle with a compiled v0.7.1 CLI and deliberately skipped ordinary stable packaging; do not reuse that bundle or cherry-pick the candidate commits. This release workflow instead builds the helper on an arm64 Mac runner, transfers it by Actions artifact to Linux cross-compilation, and preserves the four raw stable asset names expected by the v0.7.1 updater. The build interface assumed from the embedding worker is `--live-lab-helper=<path>` and must embed only for darwin-arm64. Preparation workflow_dispatch uploads artifacts only; stable tag push publishes after dependent tests. Native helper links Apple platform frameworks, no bundled external native library. See support/release-v0.8.0.md for the remaining physical Mac gates and preparation steps. No release was published or tagged in this work. Values unchanged: existing truthful-release and preservation lessons apply.
