Protocol v1: launch emits hello with protocol 1 without accessing mic. Only explicit `start()` sends start and waits for ready; capture events carry strict 640-byte PCM16 mono 16k (20 ms), play accepts nonempty even-length PCM16 mono 24k up to 1s, flush requires a strictly increasing generation and play uses current generation. Audio samples are neither logged nor retained after callbacks/writes. `played(queuedMs)` and capture frame/byte counters are metadata only. Stop waits for stopped with bounded timeout, then kills. Untrusted helper error text/stderr never reach user callbacks. A missing helper does not trigger a download: default `dist/live-lab-helper` relative to working directory, or caller-supplied trusted developer path. Real launch requires local interactive macOS terminal; tests inject a fake process and never touch devices, APIs, or keys.
