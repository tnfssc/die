Official npm registry `https://registry.npmjs.org/@google%2fgenai/latest` reported 2.24.0 on 2026-09-23; pinned exact. Source/type contract: installed `node_modules/@google/genai/dist/genai.d.ts` (LiveConnectConfig, LiveCallbacks, LiveServerContent, LiveSendRealtimeInputParameters). SDK uses `GoogleGenAI.live.connect`, typed messages, `sendRealtimeInput`; no ad hoc websocket schema. SDK declares FunctionResponse scheduling/willContinue; irrelevant here. SDK Node >=20, transitive ws/google-auth-library/protobufjs: **Bun single-binary bundling and native Mac runtime compatibility unproven**. No real credentials, calls, microphone or speaker used.

`VoiceSession` is single-use: explicit `connect(apiKey)` only; `onReady` after SDK setup/connect resolves; `onState` connecting/ready/closed; sends only in ready; `endAudio` sends one `audioStreamEnd` while stream idle and later audio reopens. Provider automatic VAD remains default: endAudio means microphone stream ended, not a local silence timeout. `close` is idempotent; invalid or late callbacks after close are ignored and a late-resolving SDK connection is closed. No reconnect or replay: GoAway emits sanitized `expiring` and closes immediately; restart requires a new instance and may lose context. SDK connect can remain pending if socket closes before setupComplete; explicit close invalidates callbacks but cannot abort SDK's pending promise without SDK support; controller must not await it indefinitely.

Callback audio is base64 PCM16 24 kHz, input is base64 PCM16 16 kHz. Per-packet bounds: input <=3200 bytes (100 ms), output <=96000 bytes (2 s), even nonzero byte count and base64 shape; transcript <=4096 UTF-16 code units per event (oversize transcript skipped without dropping turn markers). Capture should frame <=100 ms and playback must bound its own queue. Output invalidity closes rather than forwarding unsafe bytes. Input validation reports sanitized errors and drops chunk. No transcript/audio/key/raw SDK error is saved or logged. No text/tool handoff. TurnComplete is delivered even alongside final transcript; generation increments after turnComplete and immediately on interruption. Playback controller must flush audio from older generations on interrupt/close; output transcripts following interruption carry new generation. No assumption that generationComplete means playback complete. Callback exceptions are not caught except as connect failure during startup; controller should keep callbacks nonthrowing.
