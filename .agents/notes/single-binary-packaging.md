## Architecture / why
1. Normal build constructs pinned patched T3 frontend/backend, deploys its production graph, packs deterministic gzip manifest+bytes preserving internal pnpm symlinks/executable bits, embeds archive with Bun file import, compiles ONE executable. No runtime web download or external Node/Bun installation.
2. First die web extracts under private XDG_CACHE_HOME/die/web-runtime/<archiveSHA256> (default ~/.cache/die/web-runtime). Unique staging siblings + complete marker + atomic rename; concurrent starts converge. Tests cover determinism, corrupt payload cleanup, concurrent first starts, symlink-target rejection, modes, and reuse. CLI-only starts do not extract web.
3. Compiled Bun IN-PROCESS dynamic import failed real createRequire(@ff-labs/fff-node) resolution despite package existing. Self-exec interpreter proof succeeded. Parent therefore starts its own executable with BUN_BE_BUN=1 on extracted bootstrap.mjs; bootstrap immediately deletes flag before backend import. Backend exports runCli(args): Promise<number> with explicit args, Effect scoped services, signal/teardown lifetime. Parent forwards signals to OWN child.
4. Static node:sea import replaced by optional process.getBuiltinModule lookup. SEA classification stays SEA-only: Bun.main===execPath was empirically false and Die is not T3 hidden-command entrypoint. LocalDeviceHost/AgentDeviceShim/Claude JS helper invocations explicitly opt into Bun interpreter env; Pi/provider CLI children strip it. Shim POSIX prefix is BUN_BE_BUN=1 exec. Agent-device actual compiled two-hop fixture passed.
5. IMPORTANT second real blocker: Bun1.4.1 + node-pty1.1.0 interactive tty.ReadStream emits EAGAIN, closes master, shell exits SIGHUP within milliseconds. Short noninteractive PTY proofs missed this. Direct delayed-interactive proof + browser (draft AND persisted thread) reproduced it. Bun native Terminal works. Added small BunPtyAdapter; select it before loading node-pty when hosted by Bun. Supports buffered early data/exit, write, resize, kill, signal mapping, handle close. Native delayed shell/resize/exit/kill tests passed. Node development fallback remains.
6. Old Node sidecar launchers removed. Local installer copies only executable. Release publishes one executable + checksum/licenses/source, no web tarball. CI now installs pinned build-time pnpm too. Release gate includes native Bun PTY tests. Build-time Node24/pnpm remain necessary for upstream tools, not runtime.
