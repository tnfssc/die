Run JS/TS code in current directory. Top-level await, import/export, require(), Bun/Node/Web APIs, local modules, and installed packages all work. `await showImage(image)` shows image to you. Pass file path, Blob, Uint8Array, Buffer, or ArrayBuffer. PNG, JPEG, and WebP work. Max 4 images per execute call. Input max 25 MB. Images over 5 MB resized automatically; original stays same. Output max 5 MB each, 10 MB together. Text output up to 4,000 characters comes back directly. Longer output spills to files within a shared 10 MiB stdout/stderr capture limit. Set outputByteLimit per execution to change it; truncation is reported explicitly. You get a short preview and file paths.
