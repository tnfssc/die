Run JS/TS code in current directory. Top-level await, import/export, require(), Bun/Node/Web APIs, local modules, and installed packages all work. `await showImage(image)` shows image to you. Pass file path, Blob, Uint8Array, Buffer, or ArrayBuffer. PNG, JPEG, and WebP work. Max 4 images per execute call. Input max 25 MB. Images over 5 MB resized automatically; original stays same. Output max 5 MB each, 10 MB together. Text output up to 4,000 characters comes back directly. Longer output spills to files within a shared 10 MiB stdout/stderr capture limit. Set outputByteLimit per execution to change it; truncation is reported explicitly. You get a short preview and file paths. For shell commands or delegation, call the shell() or subagent() globals inside execute; no die module import is needed. Their access to files, workers, or network depends on the actual environment and result.

Live voice: `await live.stop()` stops this agent session’s active microphone, playback, and provider connection. Wait for its result before saying it stopped; `stopped: false` includes teardown errors. Jobs keep running. For an explicit request to stop one job, use `jobs.stop(exactId)`; for current-session work use `jobs.stopWork()` with its existing confirmation. The latter includes foreground cancellation after report delivery. If both voice and work must stop, await live.stop first. Ordinary speech interruption does not stop jobs or Live.

Questions: `await questions.ask({text, blocked:true, dedupKey?})` saves a persistent question and returns immediately (it does not wait for a reply). Use only when work is actually blocked; use the same dedupKey to retry the same request. `questions.list()` and `questions.get(id)` inspect this branch. To explicitly answer/cancel, pass `{id,owner,version,text}` or `{id,owner,version}` using the saved question’s owner and version. Answers are saved before a parent new-turn continuation; they cannot resume a native child in place. Normal chat or Live interruption does not implicitly answer a question.
